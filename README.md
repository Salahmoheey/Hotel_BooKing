# Hotel_BooKing
Project Overview

This project analyzes hotel booking data using Microsoft Excel. The dashboard provides insights into booking trends, cancellations, and revenue performance through interactive visualizations and KPIs.

Pivot Tables

Dashboard Pages

Cancellation Analysis
Revenue Analysis

Key Insights

City Hotel generated the highest revenue.
Couples contributed the largest share of revenue.
2016 recorded the highest revenue.
The cancellation rate reached 37%.
Long lead-time bookings had the highest cancellation rate.
Repeat guest rate was only 3.19%.

Business Recommendations

Improve customer loyalty programs.
Reduce cancellations through better booking policies.
Focus marketing campaigns on couples.
Increase investment in City Hotel.
Monitor high-risk payment methods.
